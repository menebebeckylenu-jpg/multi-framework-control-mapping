# Governance, Risk & Compliance (GRC) Portfolio

Welcome to my GRC & Compliance-as-Code repository. I created this portfolio to demonstrate how modern compliance frameworks, risk assessments, and security policies can be managed transparently using version control and structured data.

## Repository Contents

### 1. [Multi-Framework Control Mapping](./control-mapping)
* **File:** `control-mapping/security-control-matrix.csv`
* **Focus:** Maps core security and privacy controls across **ISO 27001:2022**, **SOC 2**, and **NDPA/GDPR** alongside required audit evidence.

*(Upcoming modules: Information Security Policies, AI Acceptable Use Governance, and Third-Party Vendor Risk Checklists).*

---

## Core Compliance Skills Demonstrated
* **Regulatory Alignment:** Cross-mapping technical controls to avoid duplicate audit work.
* **Audit Readiness:** Defining clear, verifiable audit artifacts for every control.
* **Compliance-as-Code:** Utilizing Git, Markdown, CSVs, and Pull Requests to maintain tamper-evident audit trails.
