# Multi-Framework Security & Privacy Control Matrix

## Overview
Organizations operating in modern tech environments rarely comply with a single regulation. This matrix demonstrates a **"Map Once, Comply Many"** approach by aligning 10 foundational technical and administrative controls across three major frameworks:
* **ISO/IEC 27001:2022** (International Information Security Standard)
* **SOC 2 Trust Services Criteria** (Security, Availability, and Privacy)
* **Data Privacy Laws (NDPA / GDPR)** (Data Protection Principles & Technical Safeguards)

## How to Use This File
* Open `security-control-matrix.csv` to search or filter controls by domain (e.g., `Access Control`, `Data Protection`).
* Review the **Implementation_Evidence** column to see the exact audit artifacts required to prove compliance during an external audit.
